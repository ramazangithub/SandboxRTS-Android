# SandboxRTS MVP economy (draft v1)

- Start: 1300 cubes per player (MVP build, see Player.cpp).
- HQ is the first building (default at start); it gives build cells and small vision.
- Build order: Construction Yard -> Supply Center -> Power Plant -> Barracks -> Factory.
- HQ level 2 unlocks Vehicle Factory (Zavod mashin), factories are upgradable.
- Reference costs/roles: Art of War 3 wiki (reference only, no assets).

Status: starting cash changed; HQ placement, build-cost table and factory unlocks are NOT implemented yet.
