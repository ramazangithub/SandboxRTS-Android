# SandboxRTS MVP (experimental branch)

Branch `mvp-experimental` only; main is untouched.

## Code
- Welcome screen (`WelcomeActivity`): title, the two MVP factions, economy rules, PLAY -> game.
- Model remap (`W3DModelDraw.cpp`, `gxMvpApply`): 34 thing templates (+ general variants such as `AirF_...`) and
  `TechOilDerrick` use our `mv*.w3d` models, only if the file exists in `Art/W3D/` on the device.
  Without the model pack the game behaves exactly as before.
  - pivots TURRET / BARREL, fire point MUZZLE / MUZZLE01; recoil, muzzle flash, hide/show and particle bones cleared;
  - animations by condition: DYING -> `_die` (once), MOVING -> `_walk`, FIRING -> `_fire`, otherwise `_idle` (loop);
  - RUBBLE states -> `mvrubble`;
  - models are authored with half-footprint 1.0 and fitted to the template geometry at runtime.
- Army cap (`BuildAssistant::canMakeUnit`): 20 + 20 per finished command center, max 80.

## Economy design
Supply points + capturable oil derricks (passive income); power is occupied, not spent; army cap from HQs (done).
Next: deployment phase, per-unit cost/time table.
